# AWS Training

Este repositório foi criado para registrar minha jornada de aprendizado em Computação em Nuvem, com foco nos serviços da Amazon Web Services (AWS).

Aqui serão documentadas atividades práticas, estudos e projetos realizados durante meu aprendizado. Cada serviço da AWS terá sua própria pasta, contendo informações sobre as atividades desenvolvidas e, quando necessário, capturas de tela das etapas realizadas.

## Serviços e atividades

| Serviço | Descrição |
|---|---|
| Amazon EC2 | Criação, configuração e gerenciamento de instâncias virtuais. |
| Amazon S3 | Estudos e práticas relacionadas ao armazenamento de objetos na nuvem. |
| Outros serviços | Novos serviços e atividades serão adicionados conforme o avanço dos estudos. |
